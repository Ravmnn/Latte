# About

Latte is a framework for developing anything that uses graphics to do something,
including general desktop applications using a GUI, or even games with the
specialized engine [Milkway](https://github.com/Ravmnn/Milkway).

This is yet under initial development stages and thus, doesn't provides any documentation of how to use it.
Besides that, the API may be unstable, with some bugs. Contribution is welcome.
